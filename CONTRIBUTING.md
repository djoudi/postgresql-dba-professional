# Contribution
Créer une branche, décrire le problème et le contexte PostgreSQL/Ubuntu, ajouter un test reproductible, lancer `python3 tests/check_all.py`. Tester les modifications système dans une VM jetable. Ne pas inclure de données réelles ni de secrets. Documenter les limites et les procédures de retour arrière. Soumettre une pull request pour revue.
