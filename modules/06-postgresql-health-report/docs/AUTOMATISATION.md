# Automatisation
Installer le projet dans /opt/pg-health (propriétaire root, lecture/exécution pour le compte de surveillance). Adapter User, port, base et chemin dans le service fourni. Créer le dossier de rapports privé appartenant au compte choisi. Vérifier la connexion non interactive avant activation. Copier les unités dans /etc/systemd/system, puis sudo systemctl daemon-reload et sudo systemctl enable --now pg-health.timer. Consulter systemctl list-timers et journalctl -u pg-health.service. Un code 2 signale un rapport partiel. Prévoir une politique de conservation externe approuvée; aucun effacement automatique.
